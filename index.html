Paramètres ⚙️

Clés API pour la recherche d'images
Comment obtenir une clé TMDB :
1. Allez sur themoviedb.org
2. Créez un compte gratuit
3. Paramètres → API → Demander une clé → Usage personnel
4. Copiez la clé "API Read Access Token" ou "API Key (v3)"

Comment obtenir une clé RAWG :
1. Allez sur rawg.io/apidocs
2. Créez un compte gratuit
3. Dashboard → API Key
4. Copiez et collez ici
